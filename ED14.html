Book Name Data Structures Through C
Author/Publications Yashavant Kanetkar
Language English
Genre Education
Label ED14
Description Yashavant Kanetkar’s textbook teaches data structures using the C programming language. It introduces concepts such as arrays, linked lists, stacks, queues, trees, searching and sorting, with code examples and exercises. The focus is on understanding how structures are represented in memory and how algorithms operate on them.
